## Operational model

- Presentation mode follows script, sections, holds, pace and movement cues.
- Editing mode changes guest origins, crew positions, SR boundary, marks, route points, cue offsets, colors, symbols and optional photos.
- Browser edits are local to each device. Exported plan JSON can contain embedded photos; treat it as personal data.
- Fixture rectangles and paths are an illustrative top-down plan, not a structural capacity or obstruction certification.

## Guardrails for revisions

- Keep prize-first ordering for every Spin-the-Wheel winner and the one-by-one Best-Dressed walks.
- Keep awardee travel visible from a proposed starting point to SR to stage to SL; an unknown seat should be clearly labelled unknown.
- A prep cue is not proof that a person is already at SR.
- Keep the raffle draw onstage and leave hardware unspecified until confirmed.
- If a new client instruction conflicts with this file, document the exact source and update this context as part of the reviewed change.
